# Расписание 3333

Telegram Mini App для группы 3333 ГУАП, помогающее студентам управлять учебной жизнью.

## Возможности

- **Расписание пар** - Просмотр и управление расписанием занятий
- **Дедлайны** - Отслеживание дедлайнов с автоматическими напоминаниями
- **Напоминания в Telegram** - Уведомления о предстоящих дедлайнах
- **Голосования** - Создание и участие в групповых опросах
- **Рассылки** - Староста может отправлять объявления всем участникам
- **Мини-игры** - Играйте в 2048, Рулетку, Монополию, D20 и другие игры
- **Достижения** - Открывайте достижения и отслеживайте прогресс
- **Дни рождения** - Никогда не пропускайте дни рождения одногруппников
- **Отслеживание прогресса** - Мониторинг академического прогресса
